# Project evidence images

Add real application screenshots and walkthrough images to the matching project folder. Supported formats: PNG, JPG/JPEG, WebP, AVIF, and GIF. Keep image files free of credentials, customer data, and private account information.

Current project folders:

- `SiriFruit/`
- `NaraApp/`
- `Enterprise Vision Suite/`
- `EcoVision Spatial AI/`
- `TenderAnalyzes/`
- `SuperLearn/`

Images are loaded into the portfolio automatically and displayed on the matching project card and project page. Use descriptive filenames such as `sales-capture.webp` or `dashboard-overview.png`. The legacy `evidences_assets/` directory is also supported while existing folders remain in place.
